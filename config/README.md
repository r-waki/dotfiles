# Kanata JIS キーボード設定

[kanata-jis.kbd](./kanata-jis.kbd) は、標準的な JIS 配列を維持しながら、ホームポジションの長押しで操作レイヤーを切り替える Kanata 設定です。

## 基本動作

- `defsrc` には操作対象のキーを定義しています。対象外のキーは `process-unmapped-keys yes` により通常の入力として処理されます。
- `_` は現在のレイヤーでキーを変更せず、下位レイヤーの動作を引き継ぐ指定です。
- `process-unmapped-keys yes` により、明示的に割り当てていないキーも処理対象にします。
- `tap-hold` は、短く押すと通常のキー入力、一定時間以上押し続けるとレイヤー切り替えや別のキー操作になります。
- レイヤー切り替えには `layer-toggle` を使っています。Kanata では `layer-toggle` は `layer-while-held` と同じ動作で、トリガーキーを押している間だけ対象レイヤーが有効です。キーを離すとベースレイヤーに戻ります。

## ホームポジションからのレイヤー切り替え

ベースレイヤーでは、以下のキーをタップすると通常の文字が入力され、長押しするとレイヤーが切り替わります。

| キー | タップ | 長押し |
| --- | --- | --- |
| `a` | `a` | `num` レイヤー |
| `s` | `s` | `sys2` レイヤー |
| `d` | `d` | `sys1` レイヤー |
| `f` | `f` | `cmd` レイヤー |
| `j` | `j` | `cmd` レイヤー |
| `k` | `k` | `sys1` レイヤー |
| `l` | `l` | `sys2` レイヤー |
| `;` | `;` | `num` レイヤー |

`a`、`;`、`k`、`l` の長押し判定には 300 ms、それ以外の上記キーには 200 ms を設定しています。タップ判定時間は 200 ms です。

## レイヤー別の割り当て

記載のないキーは `_` で、通常のキー入力を引き継ぎます。キー名は Kanata のキー表記です。

### `base` — 通常入力

通常の JIS 配列を維持し、上記のホームポジションキーでレイヤーを切り替えます。また、スペースキーはタップするとスペース、長押しすると `MEH`（Ctrl + Alt + Shift）になります。

| キー | 動作 |
| --- | --- |
| Caps Lock | 左 Ctrl |
| 左 Ctrl | Caps Lock |
| 無変換 | `muhenkan` キーを送信（IME を OFF） |
| 変換 | `henkan` キーを送信（IME を ON） |

ベースレイヤーで物理キーをそれぞれ `muhenkan` / `henkan` として明示的に出力します。IME の ON/OFF は OS や IME のキー割り当てに従います。Windows の Microsoft IME では、無変換を「IME オフ」、変換を「IME オン」に割り当ててください。

### `cmd` — 移動・編集・タブ操作

| キー | 動作 |
| --- | --- |
| `q` | Tab |
| `w` | Esc |
| `e` | Ctrl + Shift + Tab |
| `r` | Ctrl + Tab |
| `u` | Page Up |
| `o` | Backspace |
| `p` | Ctrl + V |
| `s` | タップ: Delete / 長押し: Home |
| `d` | タップ: Page Down / 長押し: 押している間 Ctrl + Shift |
| `h` | 左矢印 |
| `j` | 下矢印 |
| `k` | 上矢印 |
| `l` | 右矢印 |
| `;` | Enter |
| `n` | Page Down |
| `m` | End |
| `,` | Home |

### `sys1` — 記号入力

| キー | 出力 |
| --- | --- |
| `q`〜`p` | `1`〜`0` の Shift 付きキー（`S-1`〜`S-0`） |
| `a` | `` ` `` |
| `s` | `-` |
| `d` | `=` |
| `f` | `\` |
| `g` | Shift + `\` |
| `h` | Ctrl + 左矢印 |
| `j` | Ctrl + 下矢印 |
| `k` | Ctrl + 上矢印 |
| `l` | Ctrl + 右矢印 |
| `;` | `]` |
| `,` | Shift + `-` |
| `.` | Shift + `=` |
| `/` | `[` |
| `ro` | `]` |

### `sys2` — クリップボード操作

| キー | 動作 |
| --- | --- |
| `y` | Ctrl + V |
| `b` | Ctrl + C |

### `num` — 右手テンキー

| キー | 出力 |
| --- | --- |
| `u` `i` `o` `p` | `7` `8` `9` `0` |
| `j` `k` `l` `;` | `4` `5` `6` `.` |
| `m` `,` `.` | `1` `2` `3` |

## 時間設定

| 設定 | 値 | 用途 |
| --- | --- | --- |
| `tap-time` | 200 ms | タップ／ホールド判定のタップ時間 |
| `hold-time` | 200 ms | 標準のホールド判定時間 |
| `hold-time-slow` | 300 ms | 一部キーに使う長めのホールド判定時間 |
