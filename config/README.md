# Kanata JIS キーボード設定

[kanata-jis.kbd](./kanata-jis.kbd) は、コンパクトな JIS 配列をベースに、ホームポジションの長押しや同時押しで操作レイヤーを切り替える Kanata 設定です。設定ファイルを正として、この README では各レイヤーの動作を説明します。

## 基本動作

- `defsrc` は、物理キーボード上のキーを定義しています。テンキーとナビゲーションクラスターは含みません。
- Windows では、最上段左端の JIS キーを `grv` として定義しています。
- `_` は、そのレイヤーでキーを変更せず、通常のキー入力を引き継ぐ指定です。
- タップ・ホールド判定では、短く押すと通常のキー入力、長押しするとレイヤー切り替えなどの動作になります。
- `concurrent-tap-hold yes` により、複数の tap-hold キーを続けて押した場合も、後から押したキーの判定を並行して開始します。

## ベースレイヤーからの切り替え

| キー | タップ | 長押し |
| --- | --- | --- |
| `a` / `;` | 通常のキー入力 | `num` |
| `s` / `l` | 通常のキー入力 | `cmd1` |
| `d` / `k` | 通常のキー入力 | `cmd2` |
| `v` / `n` | 通常のキー入力 | 左 Alt を押しながら `win-switch` |

`s` と `d`、または `k` と `l` の同時押しで `cmd3` に切り替わります。各レイヤーは押している間だけ有効です。

タップ時間と通常のホールド時間はそれぞれ 200 ms です。設定ファイルでは 300 ms の `hold-time-slow` も定義されていますが、現在の割り当てでは使用していません。同時押しの判定時間は 50 ms です。

## レイヤー別の割り当て

記載のないキーは通常のキー入力を引き継ぎます。キー表記は Kanata の表記で、`S-` は Shift、`C-` は Ctrl、`A-` は Alt を表します。

### `base` — 通常入力

通常の JIS 配列で入力します。上記のキーを長押し、または同時押しすると各レイヤーに切り替わります。Caps Lock、左 Ctrl、無変換、変換などは、このレイヤーでは別のキーに置き換えていません。

### `cmd1` — 移動・ウィンドウ操作

| キー | 動作 |
| --- | --- |
| `q` | Shift + Tab |
| `w` | Tab |
| `e` | Esc |
| `y` | F2 |
| `u` | Page Up |
| `o` | Backspace |
| `p` | Delete |
| `d` | Page Down |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右矢印 |
| `;` | Enter |
| `x` | Alt + F4 |
| `n` / `m` | Home / End |

### `cmd2` — 編集・移動

| キー | 動作 |
| --- | --- |
| `q` / `w` / `e` | Shift + Tab / Tab / Esc |
| `y` | Ctrl + Y |
| `u` | Ctrl + Page Up |
| `i` | Ctrl + Shift + L |
| `a` | Ctrl + A |
| `d` | Ctrl + Page Down |
| `f` | Ctrl + F |
| `h` / `j` / `k` / `l` | Ctrl + 左 / 下 / 上 / 右矢印 |
| `;` | Enter |
| `z` / `x` / `c` / `v` | Ctrl + Z / X / C / V |
| `n` / `m` | Ctrl + Home / End |
| `,` / `.` | Ctrl + `+` / `-` |

### `cmd3` — 選択範囲の移動

| キー | 動作 |
| --- | --- |
| `q` / `w` / `e` | Shift + Tab / Tab / Esc |
| `u` | Ctrl + Shift + Page Up |
| `d` | Ctrl + Shift + Page Down |
| `h` / `j` / `k` / `l` | Ctrl + Shift + 左 / 下 / 上 / 右矢印 |
| `n` / `m` | Ctrl + Shift + Home / End |

### `num` — 数字・ファンクションキー

| キー | 出力 |
| --- | --- |
| `q` / `w` / `e` | F9 / F8 / F7 |
| `a` / `s` / `d` | F6 / F5 / F4 |
| `z` / `x` / `c` | F3 / F2 / F1 |
| `u` / `i` / `o` | 7 / 8 / 9 |
| `j` / `k` / `l` | 4 / 5 / 6 |
| `n` / `m` / `,` | 1 / 2 / 3 |

### `win-switch` — ウィンドウ切り替え

`v` または `n` を長押しすると、左 Alt を押しながらこのレイヤーが有効になります。

| キー | 動作 |
| --- | --- |
| `s` / `d` | Tab / Shift + Tab |
| `u` / `i` / `o` | 7 / 8 / 9 |
| `j` / `k` / `l` | 4 / 5 / 6 |
| `n` / `m` / `,` | 1 / 2 / 3 |
